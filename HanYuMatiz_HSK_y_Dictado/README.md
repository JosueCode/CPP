# HanYuMatiz · HSK y Dictado

Para estudiar, descarga **HanYuMatiz_HSK_y_Dictado.zip**, extráelo y abre el HTML. No necesitas instalar Node.js ni Python.

[Descargar ZIP con el HTML](https://raw.githubusercontent.com/JosueCode/CPP/hanyumatiz-hsk-dictado/HanYuMatiz_HSK_y_Dictado/HanYuMatiz_HSK_y_Dictado.zip)

Incluye 236 palabras, 20 lecciones, 74 pares y 277 situaciones. Cada lección presenta las palabras antes de los ejercicios. La selección HSK distingue la referencia de 5400 posiciones del contenido que ya tiene ejercicios.

Dictado permite pegar texto o extraerlo de JPG/PNG/WebP y PDF digitales o escaneados. El procesamiento ocurre en el navegador y exige revisar y confirmar el texto. Las respuestas se corrigen por carácter y puedes repasar solo las frases falladas.

La escucha necesita una voz de mandarín disponible en el navegador o el sistema. Las voces remotas requieren permiso. El OCR puede confundir caracteres; revisa especialmente fotos borrosas, manuscritos y páginas complejas. Las pruebas usaron Chromium y una imagen sintética de aspecto fotográfico, no una cámara física ni un libro físico. No se comprobó reproducción audible en el entorno de construcción sin voces chinas.

El ZIP **HanYuMatiz_Node_PostgreSQL.zip** es la fuente para desarrollar o publicar. Su docs/DEPLOY.md explica `npm run build` y la publicación de `dist/index.html` en hosting estático HTTPS, además de la variante conectada con reportes privados. Los dictados y documentos personales no se suben al servidor.

Licencias y atribuciones acompañan ambas entregas; SHA256.json permite comprobar las descargas. Esta rama contiene archivos descargables; no configura un hosting web externo.
