# HanYuMatiz V29

Descarga **HanYuMatiz_V29_HTML.zip**, extráelo y abre **HanYuMatiz_V29.html**. Funciona sin conexión. **HanYuMatiz_V29_Fuentes.zip** incluye fuentes editables, instrucciones, informe de validación y 97 capturas propias.

V29 reconstruye la navegación de aprendizaje, herramientas y actividad respecto a V28. Las preguntas usan una región central y acciones persistentes. Los datos lingüísticos y el planificador se conservan. El selector refleja dificultad editorial; no niveles HSK validados.

Validación: 15/15 comprobaciones de interfaz en Chromium, nueve resoluciones y zoom nativo al 200 %. Consulta docs/ENTREGA_V29.md y docs/VALIDACION_V29.json. Las capturas de capturas/ son resultados implementados.
